Обзор
ECMV — это проект прошивки в одном файле для камерных плат ESP32-S3. Он объединяет мониторинг камеры, веб-центр настроек, Wi-Fi AP/STA, BLE-провижининг, обнаружение USB Host, хранение на SD-карте и LittleFS, локальный предпросмотр на ST7789 TFT, физические кнопки и простой движок GPIO-скриптов.

Основные возможности
Просмотр JPEG-изображения с камеры в браузере в реальном времени

Веб-центр настроек камеры, сенсора, сети, хранения, TFT, кнопок и скриптов

Wi-Fi точка доступа AP и подключение к роутеру STA

BLE-провижининг и скрипты по подключению/отключению BLE

Обнаружение подключения/отключения USB Host и скрипты-триггеры

Скачивание снимков и записи из браузера

Запись MJPEG на стороне устройства

Управление файлами на SD-карте и LittleFS

Локальный предпросмотр и страница статуса на ST7789 240x320 TFT

Две настраиваемые физические кнопки

В режиме только TFT удержание обеих кнопок 5 секунд восстанавливает веб и Wi-Fi

Примечание: TFT и USB OTG используют GPIO19/20. В режиме по умолчанию "Web + TFT" SD и USB Host приостановлены. Для использования SD или USB Host переключитесь в режим "только Web" и перезагрузите устройство.

Режимы работы
Web + TFT: режим по умолчанию. Включает Wi-Fi, веб и TFT. SD и USB Host приостановлены из-за мультиплексирования выводов.

Только Web: отключает TFT и включает функции SD-карты и USB Host. Требуется перезагрузка.

Только TFT: отключает Wi-Fi и веб. Только локальный предпросмотр TFT. Требуется перезагрузка. Удерживайте обе кнопки 5 секунд, чтобы восстановить веб и Wi-Fi.

Зависимости сборки
Используйте Arduino IDE или PlatformIO для ESP32-S3. Необходимо включить PSRAM.

Основные зависимости:

esp32-camera

WiFi и WebServer

LittleFS и SD_MMC

NimBLE-Arduino

Adafruit GFX

TJpg_Decoder

Компоненты ESP-IDF USB Host

Использование
После прошивки устройство запускает Wi-Fi точку доступа. SSID по умолчанию: ECMV, пароль по умолчанию: ecmv123456.

Подключитесь к точке доступа и откройте веб-страницу устройства.

В центре настроек задайте разрешение, качество JPEG, параметры сенсора, TFT, место хранения и сеть.

Для провижининга через BLE запишите JSON в характеристику RX устройства ECMV-BLE:
{"ssid":"MyWiFi","pass":"12345678"}

На странице файлов доступны предпросмотр, скачивание и удаление.

На страницах OTG и скриптов настраиваются состояние USB Host, скрипты подключения/отключения USB, BLE-триггеры и простые GPIO-скрипты.

Формат скриптов
Одна команда на строку:

GPIO=2:1
DELAY=500
GPIO=2:0
Разрешённые GPIO для скриптов: 1, 2, 3, 14, 21, 41, 42, 47, 48. Выводы камеры, SD, USB, PSRAM и UART использовать нельзя.

Примечания
Многие выводы мультиплексированы. После смены режима работы требуется перезагрузка.

Для режима USB Host на интерфейсе должно быть питание VBUS 5V.

Проект не отправляет нажатия клавиш подключённым телефонам или компьютерам и не выполняет команды хоста.

Поддержка управления сенсором зависит от модели сенсора. Неподдерживаемые пункты пропускаются.

Назначение выводов SD-карты и TFT зависит от платы. Перед использованием проверьте схему.
